Converter JPG para PDF

Junte fotos, digitalizações e capturas de tela em um único PDF.

🔒 Privado: seus arquivos não saem do seu dispositivo

Como fazer: converter JPG para PDF

  1. Escolha suas imagens ou arraste-as para a caixa.
  2. Use as setas para definir a ordem das páginas.
  3. Escolha o tamanho da página e a margem.
  4. Clique em "Criar PDF" para baixar.

Ótimo para enviar fotos de recibos, documentos de identidade ou formulários assinados como um único documento organizado. Escolha A4 ou Carta (EUA) para páginas que imprimem bem, ou deixe cada página do tamanho da imagem.

Grátis, privado e sem cadastro

O LocalFileKit funciona inteiramente no seu navegador. Seus arquivos são processados no seu próprio dispositivo e nunca vão para um servidor, então continuam privados: sem espera de upload, sem conta e sem marca d'água.

Perguntas frequentes

Quais tipos de imagem funcionam?

JPG, PNG, WebP, GIF e BMP. Cada imagem vira uma página.

O PDF vai imprimir bem?

Escolha A4 ou Carta (EUA) com margem pequena para uma impressão limpa.

Minhas imagens são enviadas para algum servidor?

Seus arquivos nunca saem do seu dispositivo. Tudo funciona dentro do navegador: nada é enviado, não há fila de espera e nada fica guardado em um servidor.
