Redimensionar imagens

Mude as dimensões de uma imagem em pixels ou porcentagem, para uma foto ou uma pasta inteira.

🔒 Privado: seus arquivos não saem do seu dispositivo

Como fazer: redimensionar imagens

  1. Escolha suas imagens ou arraste-as para a caixa.
  2. Escolha pixels ou porcentagem e digite o tamanho que você quer.
  3. Mantenha o formato original ou mude para JPG, PNG ou WebP.
  4. Baixe as imagens redimensionadas.

Digite só a largura ou só a altura e o outro lado é calculado para você, então nada fica esticado. Preencha os dois para definir um tamanho exato.

Grátis, privado e sem cadastro

O LocalFileKit funciona inteiramente no seu navegador. Seus arquivos são processados no seu próprio dispositivo e nunca vão para um servidor, então continuam privados: sem espera de upload, sem conta e sem marca d'água.

Perguntas frequentes

Como mantenho a proporção?

Preencha só a largura ou só a altura. O outro lado é calculado automaticamente.

Posso aumentar uma imagem?

Sim, mas aumentar não acrescenta detalhes, então ampliações muito grandes ficam sem nitidez.

Que tamanho devo usar para o Instagram ou para um site?

Os posts do Instagram ficam melhores com 1080 px de largura. Para a maioria dos sites, de 1600 a 1920 px de largura é mais que suficiente.

Minhas imagens são enviadas para algum servidor?

Seus arquivos nunca saem do seu dispositivo. Tudo funciona dentro do navegador: nada é enviado, não há fila de espera e nada fica guardado em um servidor.
