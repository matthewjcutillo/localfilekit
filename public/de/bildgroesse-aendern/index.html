Bildgröße ändern

Ändere die Abmessungen eines Bildes in Pixeln oder Prozent – für ein einzelnes Foto oder einen ganzen Ordner.

🔒 Privat: Deine Dateien verlassen nie dein Gerät

So geht’s: Bildgröße ändern

  1. Wähle deine Bilder aus oder zieh sie in das Feld.
  2. Wähle Pixel oder Prozent und gib die gewünschte Größe ein.
  3. Behalte das Originalformat oder wechsle zu JPG, PNG oder WebP.
  4. Lade die angepassten Bilder herunter.

Gib nur die Breite oder nur die Höhe ein, dann wird die andere Seite automatisch berechnet und nichts wird verzerrt. Gib beide ein, um eine exakte Größe festzulegen.

Kostenlos, privat und ohne Anmeldung

LocalFileKit läuft komplett in deinem Browser. Deine Dateien werden auf deinem eigenen Gerät verarbeitet und nie an einen Server geschickt. Sie bleiben also privat: kein Warten auf den Upload, kein Konto und kein Wasserzeichen.

Häufige Fragen

Wie behalte ich das Seitenverhältnis bei?

Füll nur die Breite oder nur die Höhe aus. Die andere Seite wird automatisch berechnet.

Kann ich ein Bild vergrößern?

Ja, aber beim Vergrößern kommen keine Details hinzu, deshalb wirken starke Vergrößerungen unscharf.

Welche Größe nehme ich für Instagram oder eine Website?

Instagram-Beiträge sehen mit 1080 px Breite am besten aus. Für die meisten Websites reichen 1600–1920 px Breite völlig aus.

Werden meine Bilder hochgeladen?

Deine Dateien verlassen nie dein Gerät. Alles läuft direkt in deinem Browser: kein Upload, keine Warteschlange und nichts wird auf einem Server gespeichert.
