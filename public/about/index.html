About LocalFileKit

LocalFileKit is a set of free tools for everyday file jobs: making photos smaller, converting image formats, pulling the audio out of a video, and merging or splitting PDFs.

Every tool runs inside your web browser using modern web technology. Your files are processed on your own device and are never uploaded, which keeps them private and makes the tools fast.

The site is free to use and is supported by advertising. If something does not work the way you expect, or you would like a new tool, please get in touch.

Built with pdf-lib (MIT), PDF.js (Apache 2.0), ffmpeg.wasm (MIT / GPL), lamejs (LGPL) and JSZip (MIT). Thanks to their authors.
