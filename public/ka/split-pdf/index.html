PDF-ის დაყოფა

ამოიღეთ მხოლოდ საჭირო გვერდები ან დაყავით PDF ცალკეულ გვერდებად.

🔒 კონფიდენციალურია: ფაილები თქვენს მოწყობილობაზე რჩება

როგორ გავაკეთოთ: PDF-ის დაყოფა

  1. აირჩიეთ PDF ან გადმოიტანეთ ის ველში.
  2. აირჩიეთ „გვერდების ამოღება“ და ჩაწერეთ გვერდები, ან აირჩიეთ „თითოეული გვერდი“.
  3. დააჭირეთ ღილაკს „PDF-ის დაყოფა“.
  4. ჩამოტვირთეთ ახალი PDF ან გვერდების ZIP არქივი.

ჩაწერეთ გვერდები და დიაპაზონები, მაგალითად „1-3, 7, 10-“, და მხოლოდ ამ გვერდებისგან შეიქმნება ახალი PDF. გვერდების გამოტოვება მათი წაშლის მარტივი გზაცაა.

უფასო, კონფიდენციალური და რეგისტრაციის გარეშე

LocalFileKit მთლიანად თქვენს ბრაუზერში მუშაობს. ფაილები მუშავდება თქვენსავე მოწყობილობაზე და სერვერზე არასოდეს იგზავნება, ამიტომ ისინი კონფიდენციალური რჩება: არც ატვირთვის ლოდინია, არც ანგარიში და არც წყლის ნიშანი.

ხშირად დასმული კითხვები

როგორ წავშალო გვერდები PDF-დან?

ამოიღეთ ყველა გვერდი, გარდა იმათი, რომელთა წაშლაც გსურთ. მაგალითად, 10-გვერდიანი ფაილიდან მე-4 გვერდის მოსაშორებლად ჩაწერეთ „1-3, 5-10“.

რას ნიშნავს „10-“?

ეს ნიშნავს მე-10 გვერდიდან ბოლო გვერდამდე.

იტვირთება თუ არა ჩემი PDF ფაილები?

თქვენი ფაილები არასოდეს ტოვებს თქვენს მოწყობილობას. ყველაფერი მუშაობს თქვენს ბრაუზერში: არაფერი იტვირთება, რიგში ლოდინი არ გიწევთ და სერვერზე არაფერი ინახება.
